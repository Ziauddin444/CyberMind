2) BEGINNER QUICK START (RECOMMENDED PATH)
====================================================================

Follow these exact steps.

Step A: Go to the Flask backend

cd /Users/ziauddin/Documents/GitHub/CyberMind/backend_flask

Step B: Create and activate virtual environment

python3 -m venv venv
source venv/bin/activate

Step C: Install Python dependencies

python -m pip install --upgrade pip
pip install -r requirements.txt

Step D: Start backend

python run.py

What happens:
- It tries port 5000 first.
- If 5000 is busy, it auto-falls back to a free port in 5001-5010.
- Watch terminal logs for the final port message:
  "Dashboard: http://localhost:<PORT>"

Step E: Health check (open another terminal)

curl http://localhost:5000/api/health

If 5000 does not respond, try:

curl http://localhost:5001/api/health
curl http://localhost:5002/api/health
curl http://localhost:5003/api/health

5) COPY-PASTE API TESTS
====================================================================

Assuming backend is running on port 5000.
If needed, replace 5000 with your actual port from run.py logs.

A) Health

curl http://localhost:5000/api/health

B) Full status

curl http://localhost:5000/api/status

C) Firewall status

curl http://localhost:5000/api/firewall/status

D) Traffic translate test

curl -X POST http://localhost:5000/api/traffic/translate \
  -H "Content-Type: application/json" \
  -d '{"telemetry":["deny src=1.2.3.4 dst=10.0.0.2 port=443"],"context":{"site":"hq"}}'

E) Protected endpoint test (auth stub accepts header format only)

curl -X POST http://localhost:5000/api/blacklist/ip \
  -H "Authorization: Bearer test-token" \
  -H "Content-Type: application/json" \
  -d '{"ip_address":"999.999.999.999","reason":"test"}'

Expected: should fail as invalid IP (this is good validation and does not run firewall command).

====================================================================
6) FIREWALL ACTIONS AND PERMISSIONS (VERY IMPORTANT)
====================================================================

This project is NOT a custom firewall.
It orchestrates native OS firewalls.

That means real enforcement actions require elevated privileges:
- macOS/Linux: sudo
- Windows: Administrator shell

If you call a real firewall action without privileges, you will see errors like:
- permission denied
- requires elevated privileges

For safe beginner testing:
- Use health/status/translation endpoints first.
- Use invalid IP test on blacklist endpoint to test request flow without native firewall execution.

====================================================================
7) HOW TO STOP SERVICES
====================================================================

If backend is running in foreground terminal:
- Press Ctrl + C

If backend is running in background and you need to kill it:

pkill -f "backend_flask/run.py"

If a specific port is blocked:

lsof -i :5000
kill -9 <PID>

8) TROUBLESHOOTING
====================================================================

Problem: python run.py exits with code 1
Possible causes:
- Port in use
- Missing dependencies
- Wrong environment activated

Fix:
1) Ensure venv active:
   source /Users/ziauddin/Documents/GitHub/CyberMind/backend_flask/venv/bin/activate

2) Reinstall dependencies:
   pip install -r /Users/ziauddin/Documents/GitHub/CyberMind/backend_flask/requirements.txt

3) Start again:
   cd /Users/ziauddin/Documents/GitHub/CyberMind/backend_flask
   python run.py

4) Read logs if running background:
   tail -n 100 runtime.log


Problem: Frontend shows API errors
Cause:
- Frontend still contains legacy API calls not yet fully mapped to Commander Flask endpoints.

Temporary workaround:
- Validate backend via curl/Postman first.
- Integrate frontend routes incrementally to the new endpoints listed above.


Problem: Permission prompt or sudo required
Cause:
- Native firewall operation requested.

Fix:
- Run backend in elevated shell when testing real block/isolation actions.
